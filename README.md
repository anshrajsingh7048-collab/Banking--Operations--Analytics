# Banking Operations & Digital Payments Analytics

An end-to-end data analytics project analyzing banking transaction patterns, customer payment behaviors, failure rates, and SLA breaches across UPI, Cards, and Net Banking.

##  Repository Structure
- **`data/`**: Raw and cleaned transaction datasets.
- **`python/`**: Data cleaning and EDA automation scripts.
- **`SQL/`**: Business aggregation and KPI analytical queries.
- **`Power BI/`**: Interactive .pbix dashboard and report screenshots.

## Tools & Technologies Used
- **Python** (Pandas, NumPy)
- **SQL**
- **Power BI Desktop**

## how to Run
1. Run `python python/data_cleaning.py` to clean raw data.
2. Run `python python/analysis.py` for EDA metrics.
3. Execute queries in `SQL/analysis_queries.sql` on SQL database.
4. Open `Power BI/project.pbix` in Power BI Desktop to view dashboards.
